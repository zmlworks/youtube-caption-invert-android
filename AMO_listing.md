# AMO 公開用テキスト — YouTube inverted color subtitle for Android 2.6.0

## Summary / 概要（250 文字以内）
**English:** Make YouTube captions easier to read on Firefox for Android: invert, invert + outline, or double edge. Tap a caption to switch modes. Adjustable size, height and colors.

**日本語:** Android 版 Firefox で YouTube の字幕を読みやすくします（色反転・輪郭つき色反転・二重フチ）。字幕をタップするとモードが切り替わります。サイズ・高さ・色も調整できます。

## Description / 説明

**English**
Makes YouTube captions readable on any background on Firefox for Android (m.youtube.com and the desktop site).
- Modes: Invert (caption colors are inverted against the video), Invert + outline, Double edge (custom RGB colors; blue preset by default).
- Tap a caption to switch: Invert → Invert + outline → (caption height back to default) → Double edge → Off. This applies to the current page only; reload the page to return to your saved settings. Tapping a caption never pauses the video or opens the player controls.
- Settings: on/off, mode, caption size (matches YouTube's own sizes), caption height (10 steps), centering, outline width, double-edge colors.
- Japanese and English; follows the browser language.
- No data collection. Runs only on youtube.com / youtube-nocookie.com.

**日本語**
Android 版 Firefox（m.youtube.com とデスクトップ版サイト）で、YouTube の字幕をどんな背景でも読みやすくします。
- 動作: 反転（動画に対して字幕の色を反転）、反転 + 輪郭、二重フチ（RGB で色を指定。初期値は青）。
- 字幕をタップすると「反転 → 反転 + 輪郭 →（高さを標準に）→ 二重フチ → OFF」と切り替わります。切り替えはそのページだけで、再読み込みすると保存した設定に戻ります。字幕のタップで動画が止まったり操作パネルが出たりはしません。
- 設定: オン/オフ、動作、字幕サイズ（YouTube の字幕サイズと同じ倍率）、字幕の高さ（10 段階）、中央寄せ、輪郭の太さ、二重フチの色。
- 日本語・英語（ブラウザの言語に合わせて自動）。
- データの収集はありません。youtube.com / youtube-nocookie.com でのみ動作します。
